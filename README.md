\# Hagerstown Light Website



A modern redesign of the Hagerstown Light Department website.



\## Vision



This project is being built from the ground up using modern web technologies.



\### Goals



\- Modern responsive website

\- Employee CMS

\- SharePoint integration

\- Microsoft 365 Authentication

\- Weather API

\- Outage Management System (OMS)

\- GIS Mapping

\- Azure Hosting
